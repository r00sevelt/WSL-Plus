# ADR 决策档案（**先读这个再决策**——每条都不可随意推翻）

| ADR | 决策 | 理由/依据 | 变更条件 |
|---|---|---|---|
| #1 | btrfs 根盘 + @ 子卷（替代 ext4） | WSL 内核原生 btrfs 模块；子卷=快照/克隆/COW 基础（zfs=许可+内核无; xfs=无快照） | 除非发现 btrfs 致命缺陷 |
| #2 | MSIX/MSIXBUNDLE 根除（不产不引+SKIPMSIX=1） | Store 依赖/封闭格式；单 MSI 可控分发；安装链跳过官方 MSIX 动作（修复"找不到包"） | 不可逆 |
| #3 | 命令面=**叠加式**（修订：曾"替换式"—ADR#3 旧版） | 命令残缺是用户可感知缺损；官方 --xxx 全兼容 + 扩展子命令（snapshot/…） | 待 P0 实现后条款固化 |
| #4 | UpgradeCode 保持官方（6D5B792B-…） | 覆盖升级官方版能力是产品价值（数据/发行版保留） | 除非做完全独立产品（换身份时同步改名） |
| #5 | 版本线 3.0.0.0，规则=发布前 `gh api` 复核官方号，≥我们→大版本+1 | 数字版本比较=升级判定；撞号=安装器混淆 | 无（流程规则） |
| #6 | 零冲突纪律：只加独立文件 + §9 修改点有限 | 上游 4 次零冲突 merge 实证（39551c56/00df65ad/25d3add3 等 200+ 文件）——项目生命线 | 无 |
| #7 | 引擎用现成的（WSL/Hyper-V 客户栈），**不自研 hypervisor/UHP 超集搁置** | 自研=引擎可行但产品层 18 万行级重写（实证）；VMware 感=管理工程投入而非引擎开源（Parallels/VirtualBox 反例） | 未来有团队+资金再议 |
| #8 | Qt 面板=独立子工程（零耦合/命令面对话），与官方 WSL Settings **共存**，V1 后评估接管 wsl-settings:// | 独立=零冲突区；官方面板仍在（默认入口兜底） | GUI V1 完工后按 ROADMAP P2 换脸 |
| #9 | WSLg/依赖组件 用官方 NuGet（`find_nuget_package`）原样 | 与官方体积/行为同源；自维护=无人无收益 | 无 |
| #10 | 交付=单包 `wsl.<版本>.x64.msi`（裸 exe 仅调试） | 收窄交付面/避免混淆（官方命名风格） | 无 |
| #11 | 构建全在云端（本地不带/不编） | 4C16G+内存约束；本地配置仅指北 | 无 |
| #12 | 快照协议=Windows 只传 action+name，命令构造在 guest（wslplus_snapshot） | 协议解耦，Windows/Linux 侧可独立测试与替换 | 无 |
